# 乡野共富内容工作台

一个以“乡村振兴 + 数字助农”为主题的静态网页项目。项目把助农商品展示、产地故事、内容生成、模板复用、技术架构、动效实验、智能流程和共富成效看板整合成一个完整的多页面单页应用，强调诚信经营、绿色发展、劳动尊重和共同富裕。

当前乡村版先作为本地新项目迭代，不上传 GitHub，不覆盖原来的抖音电商 AI 网页仓库。

## 一、主题说明

本项目选择“乡村助农电商内容工作台”作为主题，原因是：

- **积极健康向上**：页面内容围绕乡村振兴、公益助农、青年返乡、生态种植和劳动价值展开。
- **符合社会主义核心价值观**：在页面中体现富强、文明、和谐、诚信、友善等价值导向。
- **适合做丰富页面**：农产品、产地故事、内容生产、模板管理、数据看板都能自然扩展成独立页面。
- **技术展示空间足够**：可加入帧动画、滚动动画、交互卡片、数据可视化和本地状态保存。

## 三、技术亮点

- **原生 SPA 路由**：不依赖框架，通过 `app.js` 管理页面切换、状态渲染和事件绑定。
- **localStorage 持久化**：保存当前页面、表单内容、生成结果和收藏模板。
- **高级帧动画**：首页主视觉使用 `requestAnimationFrame` 驱动四季助农场景，模拟“春耕、夏长、秋收、冷链进城、公益复购”的连续变化。
- **滚动触发动画**：使用 `IntersectionObserver` 思路的可见区域检测，实现页面模块进入视口时渐显上移。
- **顶部阅读进度条**：根据页面滚动距离实时更新。
- **磁吸倾斜卡片**：商品卡、功能卡、模板卡支持指针移动时的 3D 倾斜交互。
- **技术架构页**：把状态核心、渲染映射、动画循环、事件总线做成可视化卡片和代码窗口。
- **动效实验页**：用 CSS keyframes 制作视差山野、轨道节点、扫描线等视觉实验。
- **智能流程页**：把内容生成过程拆成流程看板和终端日志式展示。
- **CSS 数据可视化**：共富看板使用 `conic-gradient` 制作评分进度环。
- **响应式布局**：CSS Grid + 媒体查询适配桌面、平板和手机。

## 五、运行方式

本项目为纯静态网页，无需安装依赖。

直接打开：

```text
index.html
```

或使用任意静态服务器：

```bash
npx serve .
```

## 六、体验流程

1. 打开首页，查看“乡村振兴与数字助农”主题和帧动画主视觉。
2. 进入“助农商品”，查看不同产区农产品和助农目标进度。
3. 进入“产地故事”，阅读返乡创业、妇女创业、生态种植等故事。
4. 进入“内容生成”，填写或使用默认商品信息，点击“生成完整方案”。
5. 查看生成的商品标题、核心卖点、短视频脚本和主图提示。
6. 点击“收藏为模板”，再到“模板工坊”查看新增模板。
7. 进入“技术架构”“动效实验”“智能流程”，查看技术展示页面。
8. 进入“共富看板”，检查项目成效和数据可视化。

## 七、与参考项目的关系

参考项目 `adrianhajdin/award-winning-website` 的特点是强视觉、强动效和沉浸式滚动体验。本项目没有引入 React、Tailwind 或 GSAP，而是在纯原生技术栈下实现类似方向：

- 使用帧动画场景增强首页记忆点。
- 使用滚动揭示和顶部进度条增强浏览体验。
- 使用 3D 倾斜卡片和动态看板提升交互感。
- 增加技术架构、动效实验、智能流程页面强化技术体量。
- 使用多页面内容结构保证体量和完整性。
